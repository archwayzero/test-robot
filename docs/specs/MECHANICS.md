# Game mechanics (human-written)

## Game summary
(One paragraph: genre, perspective, core loop, target platform.)
This is an iOS game so game data should be saved automatically to the cloud whenever player progresses.
This is a simple game in which the main character (hero) is lost in a maze. There is in fact no way out, but there should be a mini-map on the top left corner that reveals the player's position on the map. Anywhere that the player has never been to should be dark in the mini-map; once explored, it should reveal the layout. Player should be able to click on the mini-map to see a larger view of where they have been. Player should be able to walk, run, crouch, and crawl throughout the maze.
